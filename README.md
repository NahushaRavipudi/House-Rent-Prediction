# House Rent Prediction

## About the Project

I built this project to predict house rent using machine learning. I used Linear Regression and XGBoost to train models and compare their performance on the dataset.

The main goal was to understand how regression algorithms work and how they can be used to predict rental prices based on the available data.

## What I Did

- Loaded and explored the dataset.
- Prepared the data for model training.
- Split the data into training and testing sets.
- Trained a Linear Regression model.
- Trained an XGBoost Regression model.
- Evaluated the models using R² scores.
- Compared the performance of both models.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## How to Run

1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset and update the file path if needed.
4. Install any missing libraries.
5. Run the notebook cells in order.
6. Compare the R² scores of the models.

## What I Learned

While working on this project, I learned how to prepare data for regression, train machine learning models, evaluate their performance, and use the results to understand how well a model predicts house rent.
